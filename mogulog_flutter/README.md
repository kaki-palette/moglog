## まず起動確認する方法

一番簡単なのはWeb版です。

1. `D:\codexテスト\スキルテスト\mogulog_flutter` を開く
2. `run_mogulog.bat` をダブルクリック
3. `MoguLog Server` という黒い画面が開きます
4. ブラウザで `http://localhost:8765` のWebサイト版もぐログが開きます

スマホで使う場合:

1. PCとスマホを同じWi-Fiにつなぐ
2. `run_mogulog.bat` を起動したままにする
3. `MoguLog Server` の画面に出ている `http://192.168...:8765` のようなURLをスマホのブラウザで開く
4. Windowsファイアウォールの確認が出たら、プライベートネットワークで許可する

手動で開く場合は、次のURLをブラウザに入力してください。

```text
http://localhost:8765
```

## Web版の使い方

今のWeb版は、アプリ化前の「自分用グルメメモ媒体」として整理しています。スマホ画面モックではなく、PCブラウザでも広く見やすいWebサイト型レイアウトです。

## スマホで使う方法

### まず自宅Wi-Fiで試す

1. PCで `run_mogulog.bat` をダブルクリック
2. 黒い `MoguLog Server` 画面を閉じずに置いておく
3. スマホをPCと同じWi-Fiにつなぐ
4. 黒い画面に出ている `http://192.168...:8765` のURLをスマホのブラウザに入力する
5. もぐログが開いたら、右下のカメラボタンから料理写真を登録する

この方法は無料ですが、PCがサーバー役なので、PCを切るとスマホからは開けません。

### 外出先でPCなしで使う

外出先でPCなしにするには、もぐログをインターネット上のサーバーへ置く必要があります。

おすすめの進め方は次のどちらかです。

1. 無料優先: Cloudflare Pagesなどに静的サイトとして置き、スマホ本体にデータを保存する
2. 同期優先: Supabase / Firebase / Cloudflare D1などのクラウドDBを使い、スマホとPCで同じデータを同期する

無料優先はお金がかかりにくいですが、基本的にデータはそのスマホのブラウザ内保存です。同期優先は便利ですが、無料枠を超えたり設定次第で料金が発生する可能性があります。

今のコードは個人サーバー用に `MOGULOG_ACCESS_KEY` でアクセスキーを設定できるようにしています。外部公開する場合は、必ずアクセスキーを設定してください。

```bash
set MOGULOG_ACCESS_KEY=自分だけが知っている長い合言葉
npm start
```

クラウド同期を本格導入する場合は、料金が発生する可能性があるため、先にサービス候補と月額目安を確認してから進めてください。

詳しいスマホ手順は `SMARTPHONE_GUIDE.md` にまとめています。

`web_app/config.js` の `syncMode` は初期値 `auto` です。APIサーバーがある場合は同期し、Cloudflare Pagesなどの静的サイトでは自動でスマホ内保存に切り替わります。

### データ同期

`run_mogulog.bat` から起動した場合、投稿データはPC側の `web_app/data/mogulog-data.json` に保存されます。

同じPCサーバーにスマホからアクセスすると、PCとスマホで同じデータを読み書きできます。画面右上の表示が「同期済み」になれば保存完了です。

サーバーを使わずに `index.html` を直接開いた場合は、その端末のブラウザ内だけに保存されます。スマホとPCで同期したい場合は、必ず `run_mogulog.bat` から起動してください。

この方式は自分のPCを保存先にするため、追加料金はかかりません。

同じWi-Fi内からアクセスできる個人用サーバーなので、カフェやホテルなどの共有Wi-Fiでは使わず、自宅など信頼できるネットワークで使ってください。

### メモ

最初の画面に、自分のグルメカードが並びます。

カード表面には、料理写真、料理名、店舗名、一言コメント、撮影・登録したユーザー名が表示されます。

上部では、メモ数、実際に行った店、行きたい店、登録エリア数を確認できます。

検索欄では、店名、料理名、エリア、ジャンル、営業時間から探せます。

「すべて」「行きたい」「行った」の切り替えで、今すぐ見たいメモだけに絞れます。

カードの「メモに保存」を押すと、図鑑とマップに登録されます。カードをタップすると、裏面の店舗情報、営業時間、Google Mapsリンクを確認できます。

### マイ図鑑

下のメニューから「図鑑」を開くと、保存したカードが並びます。

エリア別、ジャンル別に切り替えて整理できます。図鑑内の編集ボタンから、料理名と一言コメントを編集できます。撮影者名は最初に登録した人の名前が残ります。

図鑑内のチェックボタンで「自分で実際に行った店」マークを付け外しできます。マーク済みカードには「行った」表示が付きます。

カード裏面には営業時間も表示されます。投稿・編集時に営業時間を空欄にすると、試作版ではGoogle Maps連携を想定した自動補完で営業時間が入ります。

### フレンド

フレンド、カード交換、おすそわけは、将来スマホアプリ化するときの機能としてコード側に残しています。

今のWeb版では、自分用メモとして迷わず使えるよう、通常メニューからは外しています。

### マイマップ

下のメニューから「マイマップ」を開くと、アンロック済みカードが地図ピンとして表示されます。

地図表示にはLeafletとOpenStreetMapを使っています。インターネット接続がない場合は、地図ライブラリ未読み込みの案内が出ます。

投稿時に住所を入力すると、店名・住所・エリアから無料の場所検索で座標を探して保存します。「今いる場所を使う」ボタンや緯度経度の手入力にも対応しています。

カード裏面とマップのポップアップから、保存した場所をGoogle Mapsで開けます。

マイマップ上部の検索欄は、お店の名前、食べ物名、住所、エリア、ジャンル、営業時間に対応しています。ピンを押して出るカードから、記録済みカードの削除もできます。

マップのポップアップからも「実際に行った店」マークを付け外しできます。マーク済みのお店は地図ピンにも緑の印が付きます。

### 投稿

右下の投稿ボタンからカードを作れます。

写真取り込み、料理名、店舗名、営業時間、エリア、ジャンル、一言コメント、限定フラグを入力できます。営業時間は空欄でも大丈夫です。

「AIシズル感加工を適用」をOFFにすると、写真をそのまま使う無加工カードとして登録できます。

プリセット画像は廃止しました。基本的に、自分で撮った料理写真や端末内の料理写真を選択して投稿します。

ネガティブな言葉は投稿できないようになっています。

## Flutter版をAndroidで動かす方法

Flutter SDKが入っているPCでは、Androidアプリとして起動できます。

1. Android Studio、Androidエミュレーター、またはAndroid実機を準備
2. `run_flutter_android.bat` をダブルクリック
3. Flutterが必要ファイルを作成し、Android端末で起動します

コマンドで実行する場合:

```bash
cd D:\codexテスト\スキルテスト\mogulog_flutter
flutter create --platforms=android --project-name mogulog_flutter .
flutter pub get
flutter run
```

## 注意点

Flutter版の `lib/main.dart` は、今回のコピー版をそのまま主軸として置き換えています。

このFlutter版は `dart:io` を使うため、Flutter WebではなくAndroid/iOS向けです。ChromeでのFlutter Web起動は想定していません。PCブラウザで確認したい場合は `web_app/index.html` を使ってください。

Google Mapsの公式Places APIや営業時間の自動取得を本番品質で使う場合は、Google CloudのAPIキーと請求設定が必要になる可能性があります。今のWeb版では勝手に有料APIを使わず、無料の地図表示・無料の場所検索・Google Mapsで開くリンクだけを使っています。

## セキュリティメモ

外部公開前提で、次の対策を入れています。

- 保存APIは `MOGULOG_ACCESS_KEY` を設定するとアクセスキー入力が必要になります
- `web_app/data/mogulog-data.json` はブラウザから直接読めないようにしています
- 投稿された店名・コメントなどはHTMLとして実行されないよう、表示時にエスケープしています
- `server.js` 自体もブラウザから直接読めないようにしています
- セキュリティ系のHTTPヘッダーを追加しています

ただし、外部公開するならHTTPSが必要です。現在地取得やスマホへのホーム画面追加も、基本的にHTTPSのサイトで安定します。

## スマホアプリ化について

スマホアプリ化は可能です。

AndroidはWindows PCだけでも開発・ビルドできます。最終的には、アプリアイコン、アプリ署名、Google Maps/Places API、本番用データ保存先、プライバシーポリシーなどを整えればGoogle Play向けに進められます。

iPhoneアプリ化もできますが、App Store提出用のiOSビルドにはMacとXcodeが必要です。Windowsでは主にDart/Flutterコード開発まで進め、最終ビルドだけMacで行う流れになります。
