# もぐログをスマホで使う方法

## 1. まず自宅Wi-Fiで試す

この方法は、PCをサーバーとして使います。無料ですが、PCを切るとスマホから開けません。

1. PCで `run_mogulog.bat` をダブルクリックする
2. 黒い `MoguLog Server` 画面を閉じずに置く
3. スマホをPCと同じWi-Fiにつなぐ
4. 黒い画面に出ている `http://192.168...:8765` をスマホのブラウザで開く
5. 右下のカメラボタンから料理写真を登録する

## 2. PCなしで外出先から使う

PCを起動しっぱなしにしない場合、サイトをインターネット上に置く必要があります。

追加料金を避けるなら、まずは「静的サイト + スマホ内保存」で進めるのが安全です。

### 無料優先の構成

- 配置先: Cloudflare Pages / GitHub Pages / Netlify など
- 保存先: スマホのブラウザ内
- 同期: なし
- 料金: 無料枠で始めやすい

この構成では、`web_app` フォルダの中身を静的サイトとして公開します。

公開後、スマホでURLを開き、ブラウザメニューから「ホーム画面に追加」を押すと、アプリのように起動できます。

### 同期優先の構成

- 配置先: Node.jsを動かせるサーバー
- 保存先: サーバーまたはクラウドDB
- 同期: あり
- 料金: 無料枠を超えると発生する可能性あり

この構成では、`MOGULOG_ACCESS_KEY` を必ず設定してください。

```bash
set MOGULOG_ACCESS_KEY=自分だけが知っている長い合言葉
npm start
```

クラウドDBを使う場合は、Supabase / Firebase / Cloudflare D1 などを選ぶ必要があります。料金が発生する可能性があるため、契約前に確認してください。

## 3. セキュリティ注意点

- 外部公開するならHTTPSが必要です。
- `MOGULOG_ACCESS_KEY` なしで外部公開しないでください。
- カフェやホテルなどの共有Wi-Fiで、自宅PCサーバーを公開しないでください。
- 写真・店名・住所は個人データです。公開URLを他人に共有しないでください。
